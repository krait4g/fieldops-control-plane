# README 이미지

이 디렉터리의 이미지는 FieldOps Control Plane의 제품 방향과 기능 범위를 설명하기 위한 콘셉트 이미지입니다.

- `product-vision-hero.webp` — 제품 전체 흐름을 보여주는 README Hero
- `capability-overview.webp` — 장비 연동·실시간 상태·알람·안전 제어 기능 개요
- `screen-overview.webp` — Overview·Device Detail·Camera·Command 화면 구성

세 이미지는 README용으로만 해상도와 용량을 최적화했으며, 원본 구도와 내용은 유지합니다. 실제 구현 화면이나 실측 결과로 표현하지 않습니다.
