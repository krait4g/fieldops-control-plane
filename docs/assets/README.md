# Concept Image

이 디렉터리의 이미지는 제품 방향과 기능 범위를 설명하기 위한 **Concept Visual**입니다.

- `product-vision-hero.svg` — 제품 첫 화면 Hero
- `capability-overview-concept.svg` — 장비 연동·상태·Dashboard·Alarm·제어·AI 확장 개요
- `screen-concept.svg` — Overview·Device Detail·Camera·Command 목표 화면

## 사용 원칙

- 실제 구현 Screenshot으로 표현하지 않음
- 이미지 안의 숫자·상태·Protocol을 실측값이나 완료 기능으로 해석하지 않음
- README에서 Concept임을 명시
- 실제 UI가 구현되면 첫 화면에는 실제 Screenshot을 우선 배치
- 구현하지 않은 AI·Protocol·Camera 기능은 문서 상태와 함께 표시
- 공개 이미지는 GitHub README에서 안정적으로 렌더링되는 SVG로 관리하고 실제 회사·고객·운영 데이터를 사용하지 않음
